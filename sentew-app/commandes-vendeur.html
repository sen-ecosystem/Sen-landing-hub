💡 Guide vendeur — Remise colis

1. À préparer — Nouvelle commande → touche « Préparer » pour dire au client que c'est en cours.

2. Emballe — Produit protégé, paquet fermé. Ajoute un petit mot de remerciement (fidélise !).

3. Colis prêt — Touche « Colis prêt » → le QR code s'affiche. Quand le livreur arrive, il le scanne → la commande passe « Récupérée » automatiquement, le client est notifié.

4. Pas de caméra ? — Le livreur tape le code retrait à 4 chiffres affiché sous le QR.

⚠️ Jamais sans scan — Ne remets JAMAIS un colis sans que le livreur ait validé le code : c'est ta preuve de remise. Sans ça, aucun litige possible contre toi.

💰 Paiement — Ta part (prix − commission 5%) arrive dans ta cagnotte dès la livraison confirmée, reversée chaque vendredi.
