📜 Règles du livreur SEN TEW (à lire)

1. Je ne dois jamais connaître le contenu du colis — seulement le code de livraison et les coordonnées du client.
2. Je photographie le colis au retrait chez le vendeur (preuve d'état) et je vérifie qu'il est bien emballé et couvert.
3. Pour les aliments : sac isotherme propre, respect des règles sanitaires, livraison rapide.
4. Je remets le colis uniquement contre le code secret du client — jamais sans.
5. Ma position GPS est partagée pendant la livraison, et s'arrête automatiquement après.
6. Je respecte le code de la route. Casque obligatoire en 2-roues.
