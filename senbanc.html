SENBANC ne vous demandera jamais votre code PIN, mot de passe ou code de confirmation par email, SMS ou téléphone.

🛡️ Conseils de sécurité SENBANC

Protégez-vous contre les arnaques bancaires

📧 Emails frauduleux

Ne cliquez jamais sur les liens d'emails suspects prétendant venir de SENBANC. Vérifiez toujours l'adresse expéditeur : elle doit se terminer par @sen-ecosystem.com.

📱 SMS d'arnaque

SENBANC n'envoie jamais de SMS demandant votre code PIN ou OTP. En cas de doute, appelez le service client au numéro officiel.

📞 Faux appels

Aucun agent SENBANC ne vous demandera votre mot de passe par téléphone. Raccrochez immédiatement en cas de demande suspecte.

💳 Mobile Money irréversible

⚠️ Toute transaction Mobile Money confirmée est définitive. Vérifiez toujours le destinataire avant de valider un paiement.

🎣 Phishing (hameçonnage)

Vérifiez toujours l'URL du site : https://sen-ecosystem.com. Aucun autre site ne peut vous demander vos identifiants.

🔐 Code PIN confidentiel

Ne partagez JAMAIS votre code PIN, même avec un proche. Ne l'écrivez pas et changez-le tous les 3 mois.

🚨 En cas de fraude

Contactez immédiatement notre équipe : hello.senecosystem@gmail.com ou bloquez votre compte via l'application.
